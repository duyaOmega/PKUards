# PKUARDS · 燕园争锋

一场发生在未名湖畔的校园策略卡牌交锋。四大学科阵营、64 张原创卡牌，以前线争夺和精力管理为核心，包含完整人机对局与自由组牌。

**在线游玩**：[duyaomega.github.io/PKUards](https://duyaomega.github.io/PKUards/)

**源代码**：[duyaOmega/PKUards](https://github.com/duyaOmega/PKUards)

当前发布结果见本文末尾的发布记录。

## 本地开始

电脑已有 Node.js 22 或更高版本时，双击项目根目录的 `start.cmd`，或在 PowerShell 运行：

```powershell
cd D:\PKUards
npm start
```

打开 <http://localhost:4173/PKUards/>。无需执行 `npm install`，所有游戏逻辑与插画均随项目提供，不加载 CDN、外部字体或远程 AI 服务。先点击“初来燕园？先学一手”完成三步互动教学，再选择预组出战。

手机浏览器支持竖屏游玩：左右滑动手牌，点选卡牌后再点高亮空位部署；点选场上单位，再点前线空位或攻击目标。底部保留行动提示、取消选择与结束回合。点卡牌右上角的 `i` 查看完整效果。触屏滑动用于浏览手牌和页面，鼠标仍可拖拽出牌。

## 已实现

- 64 张全部解锁的原创可组牌卡，四阵营各 12 张、中立 16 张；另有 3 种只由技能召唤的衍生伙伴。
- 理学探索、工学智造、人文思辨、社科纵横四套合法预组，每套 39 张抽取牌与 1 座基地。
- 起手换牌、逐回合精力、共享前线、五种单位、速攻/守护/隐蔽、反击与拦截、疲劳及平局。
- 不读取对手隐藏手牌和牌库顺序的本地策略 AI。
- 卡牌搜索和多条件筛选、主副阵营组牌、费用曲线、套牌合法性检查。
- 当前对局、套牌、设置和战绩独立保存，支持刷新续局与部分损坏恢复。
- 复古纸卡、木质战场、20 幅生图油画场景、中央出牌与目标动画、减少动态效果设置、点击及指针拖拽。
- 纯静态 GitHub Pages 部署，推送 `main` 后先测试再发布。

具体玩法、修改卡牌数值、调整 AI、恢复存档和部署步骤见 [docs/guide.md](docs/guide.md)。本次执行证据与验证范围见 [docs/conclusion.md](docs/conclusion.md)。

## 代码结构

| 位置 | 内容 |
| --- | --- |
| `web/data.js` | 卡牌、阵营、套牌、关键词及规则常量 |
| `web/engine.js` | 规则与状态转换，不依赖界面 |
| `web/ai.js` | 仅使用可见信息的动作评估 |
| `web/storage.js` | 分类存档与容错 |
| `web/app.js`、`web/style.css` | 游戏界面、交互与响应布局 |
| `web/art.js`、`web/assets/art/` | 20 幅生图油画的加载与轻量 WebP 素材 |
| `web/presentation.js`、`web/cinema.css` | 中央亮牌、目标指向、冲击数字和串行动画 |
| `scripts/`、`tests/` | 本地服务、自动对局与测试 |
| `.github/workflows/pages.yml` | 测试与 Pages 发布 |

## 版本记录

### 1.2.2 · 手机浏览器适配

移除对战和换牌页面的 740px 最小宽度，增加竖屏战场、可横向滚动的固定宽度手牌、底部常驻操作区、换牌自动换行，以及较大的详情按钮与表单控件。兼容安全区和动态视口高度，保留浏览器缩放。触屏改用点选行动，滑动不进入鼠标拖拽流程，重绘后保留手牌滚动位置。

验证范围：41 项自动测试通过，包含 32 场完整自动对局；CSS 通过 Lightning CSS 语法检查。触屏回归测试验证控制器事件和状态，不替代手机浏览器的原生触摸与视觉验收；本次尚未完成 iOS Safari / Android Chrome 实机验收。

### 1.2.1 · 2026-10-28

动画改为克制的桌面反馈：取消全屏暗幕、中央大标题、卡牌飞行旋转、冲撞、发光与数字弹跳。自己出牌不弹卡，对手用固定的 140px 小卡短暂展示，保留细目标线、目标边框和小幅受击数字。对手出牌约 1.09 秒，己方出牌/攻击约 0.4 秒，推进约 0.3 秒。卡牌规则、插画和存档版本保持不变。

### 1.2.0 · 2026-10-28

- 单位分类改为近战、突击、炮击、拦截、轰炸，卡名继续使用校园题材。
- 内置 image_gen 绘制 20 幅厚涂油画，用于 64 张卡牌的主题场景和首页。20 个主题按题材复用，未声称每张卡有独立插画。网页素材合计约 2.9 MiB，单文件均小于 256 KiB，原始大图不入库。完整提示词见 `docs/art-prompts.json`。
- 12 张单位增加专属能力，包括抽牌成长、推进取牌、相邻修复、事件接力、前线观测；“抢课脚本”改为重新激活友方单位。
- 双方出牌均在中央亮牌，随后指向目标，再结算伤害、治疗、强化和离场；推进与攻击有移动表现。播放期间锁定下一步，跳过动画不会重复扣费。
- 规则存档版本升级为 2：旧对局需要重新开始，套牌、战绩、设置保留。
- 真实 Edge 验收方式与证据见 `docs/guide.md`、`docs/conclusion.md`。

### 1.1.0 · 2026-10-28

新增鼠标与触屏指针拖牌、卡牌跟随、目标箭头及落点提示。支持拖牌部署、拖动推进与攻击、拖动事件选择目标；指定登场技能可先放置后选目标，也可直接拖向目标自动选择合法空位。无效落点与 Esc 取消不消耗资源。

新增对手出牌展示和最近六次出牌回看，可点击查看完整卡牌。AI 每次出牌后至少停留 1.9 秒供阅读，召唤衍生单位不重复算作手牌出牌。公开出牌记录随对局保存，兼容旧存档。

29 项自动测试通过，仍包含 32 场完整自动对局。实际 Windows 浏览器拖动验收因工具无法确认当前页面地址而未完成。

### 1.0.0 · 2026-10-28

从空项目实现完整单人人机卡牌游戏，包括规则、卡池、四套预组、教学、组牌、图鉴、保存与发布工作流。全部第三方依赖保持为空。Git 存档仅纳入源码、文档及轻量矢量素材。

本作是原创校园主题游戏。机制设计参考 [KARDS 官方入门](https://www.kards.com/how-to-play)，校园地名参考[北京大学校园资料](https://oldnews.pku.edu.cn/xwzh/fc6726b809ab40289346b7c9d9ccb4b7.htm)与[校园餐饮介绍](https://www.isd.pku.edu.cn/cn/campus/catering.php)。卡牌技能、阵营风格和文案属于游戏设定。
